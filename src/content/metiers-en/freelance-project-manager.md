## **What is a freelance project manager?**

A freelance project manager is a professional who works independently on specific projects. They are responsible for every stage of the project, from planning to execution, through monitoring and results analysis. As a freelance project manager, they are the conductor of the orchestra, making sure every stakeholder works together in harmony.

## **The skills a project manager needs**

To be effective, a project manager must master a few key skills. First, strong communication skills, since they are in regular contact with the team and the stakeholders — clear, effective communication is essential to the project's success. They must manage their time efficiently, as they are responsible for planning and organising the project's tasks. Finally, a deep knowledge of project management tools and methodologies is a must to deliver missions as a freelance project manager.

## **How a project manager's work unfolds**

A project manager's work breaks down into several key stages. First comes the planning phase, where they define the project's goals, set a schedule and identify the resources needed. Then comes execution, where they coordinate the tasks and oversee the team's work — keeping communication clear and regular with every stakeholder is essential during this phase. Once the project is delivered, they move on to evaluating and analysing the results: assessing the project's performance, identifying strengths and weaknesses, and drawing lessons for future projects. As project manager, they own all of these stages and make sure the project runs as smoothly as possible.

## **Useful tools and software for project managers**

Many tools and software help project managers run their work efficiently. There are of course project management tools such as Notion, Trello or Asana, used to plan and track the project's tasks and milestones — they help the project manager stay organised and keep an overview of progress. If you bring in a freelance project manager, you'll want to onboard them onto your collaboration tools, such as Slack or Microsoft Teams, which ease communication and coordination within the team.
